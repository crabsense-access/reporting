## Umbrales de Páginas de Ubicación

### Nivel de Aviso (30+ páginas)
- ⚠️ **AVISO** a partir de 30+ páginas de ubicación
- Exigir 60%+ de contenido único por página
- El contenido debe incluir:
  - Información local única (puntos de referencia, barrios)
  - Servicios u ofertas específicas de la ubicación
  - Información del equipo o personal local
  - Testimonios de clientes genuinos de esa zona

### Parada Obligatoria (50+ páginas)
- 🛑 **PARADA OBLIGATORIA** a partir de 50+ páginas de ubicación
- Requiere justificación explícita del usuario
- Debe demostrarse:
  - Presencia empresarial legítima en cada ubicación
  - Estrategia de contenido única para cada página
  - Señales locales (Google Business Profile, reseñas locales)

### Por Qué Importa
El algoritmo de páginas puerta de Google penaliza las páginas de ubicación programáticas con contenido escaso o duplicado. Señales de página puerta:
- Solo cambia el nombre de ciudad/estado entre páginas
- Sin información local única
- Sin señales de negocio local
- URLs saturadas de keywords

## Páginas Programáticas Seguras vs. Arriesgadas

### Seguras a Escala ✅
| Tipo de Página | Por Qué Es Segura |
|-----------------|----------------------|
| Páginas de integración | Documentación de configuración real, contenido técnico único |
| Páginas de plantilla/herramienta | Activos descargables, funcionalidad única |
| Páginas de glosario | Definiciones únicas de 200+ palabras |
| Páginas de producto | Specs, imágenes y reseñas únicas |
| Páginas de perfil de usuario | Contenido único generado por el usuario |

### Riesgo de Penalización ❌
| Tipo de Página | Por Qué Es Arriesgada |
|-----------------|--------------------------|
| Páginas de ubicación con solo la ciudad cambiada | Contenido duplicado, páginas puerta |
| "Mejor [herramienta] para [sector]" | A menudo escaso, sin valor específico del sector |
| "Alternativa a [competidor]" | Requiere datos de comparación genuinos |
| Contenido masivo generado por IA | Sin valor único, fallo de E-E-A-T |

## Requisitos del Title Tag

| Aspecto | Requisito |
|---------|-----------|
| Longitud mínima | 30 caracteres |
| Longitud máxima | 60 caracteres (Google trunca ~60) |
| Keyword primaria | Cerca del inicio |
| Nombre de marca | Al final (si se incluye) |
| Unicidad | Cada página debe tener un título único |

### Buenos Ejemplos
- "Servicios de Fontanería de Urgencia en Madrid | Fontanería ABC"
- "Cómo Reparar un Grifo que Gotea: Guía Paso a Paso"
- "Software SEO para Empresas | Plataforma Completa"

### Malos Ejemplos
- "Inicio" (demasiado corto, no descriptivo)
- "Los Mejores Servicios de Fontanería para Todas tus Necesidades en Madrid y Alrededores" (demasiado largo)
- "Fontanería ABC - Fontanería - Fontanero - Servicios de Fontanería" (keyword stuffing)

## Requisitos de la Meta Description

| Aspecto | Requisito |
|---------|-----------|
| Longitud mínima | 120 caracteres |
| Longitud máxima | 160 caracteres (Google trunca ~155-160) |
| Llamada a la acción | Incluir un CTA convincente |
| Keyword primaria | Incluir de forma natural |
| Unicidad | Cada página debe tener una descripción única |

---

## Requisitos de Alt Text de Imágenes

| Aspecto | Requisito |
|---------|-----------|
| Obligatorio en | Todas las imágenes no decorativas |
| Longitud | 10-125 caracteres |
| Contenido | Describir el contenido de la imagen, no "imagen" o el nombre del archivo |
| Keywords | Incluir de forma natural cuando sea relevante |
| Imágenes decorativas | Usar `alt=""` o `role="presentation"` |

### Buenos Ejemplos
- "Fontanero profesional reparando el grifo de la cocina"
- "Toyota Camry sedán rojo 2024, vista frontal"
- "Reunión de equipo en sala de conferencias moderna"

### Malos Ejemplos
- "imagen.jpg" (nombre de archivo, no descripción)
- "fontanero fontanería fontanero servicios" (keyword stuffing)
- "Haz clic aquí" (no descriptivo)

## Directrices de Enlazado Interno

| Tipo de Página | Objetivo de Enlaces Internos |
|-----------------|----------------------------------|
| Post de blog (1.500+ palabras) | 5-10 enlaces internos |
| Página de servicio | 3-5 enlaces internos |
| Página de categoría | Enlaces a todas las páginas hijas |
| Página de producto | 2-4 enlaces internos |

### Reglas de Anchor Text
- Usa anchor text descriptivo (no "haz clic aquí")
- Varía el anchor text (no uses siempre keywords exactas)
- Enlaza a contenido relevante y relacionado
- Evita páginas huérfanas (toda página enlazada desde al menos otra página)

## Señales de Frescura de Contenido

| Tipo de Contenido | Frecuencia de Actualización |
|---------------------|--------------------------------|
| Noticias/actualidad | En cuestión de horas/días |
| Posts de blog (perennes) | Revisar anualmente |
| Páginas de producto | Cuando cambien las specs |
| Páginas de servicio | Revisar trimestralmente |
| Información de empresa | Cuando se produzcan cambios |

### Elementos Obligatorios
- Fecha de publicación visible (para artículos/blogs)
- Fecha de última actualización (si se ha revisado significativamente)
- Changelog para actualizaciones importantes (opcional pero recomendable)
